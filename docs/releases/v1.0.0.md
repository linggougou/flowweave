# FlowWeave v1.0.0（先跑通版）

**定位**：本地网页流程自动化 MVP — 录制、入库、回放、可查。**不含 AI 编排。**

## 能力清单

- Monorepo 工程与 Flow DSL（Zod）
- 浏览器扩展录制（WXT）+ 同步本地知识库
- Electron Studio：选 Flow 运行、执行历史、Flow 版本、脆弱性提示、打开截图
- Web 控制台 + 本地 API（:3847）
- SQLite 项目知识库（`~/.flowweave/projects/`）
- Playwright 执行与 runs 产物（截图 / 页面 JSON / HAR）
- `pnpm doctor` / `pnpm smoke` / `pnpm e2e:login`

## 快速开始

见 [quickstart.md](../guides/quickstart.md)。

## macOS 安装包

Node 24 环境下执行：

```bash
pnpm --filter @flowweave/app-studio package:mac
```

默认生成：

- `apps/studio/release/mac-arm64/织流 Studio.app`
- `apps/studio/release/FlowWeave-Studio-1.0.0-arm64.dmg`

安装包包含当前 Playwright 版本对应的 headed Chromium 与 headless shell，Studio 可在不启动 Web API 的情况下直接使用本地 SQLite 知识库。

### 分发状态

- 本地预览包：已支持；使用 ad-hoc 深度签名并执行严格 bundle 校验。
- Developer ID 签名：当前未配置证书，尚未完成。
- Apple 公证：尚未完成。
- 正式品牌图标：尚未定稿，当前使用 Electron 默认图标。

因此当前 DMG 可用于本机与内部验收，不应直接作为面向外部用户的已公证安装包发布。

## 明确不包含

- LLM / NL→Flow / AI SDK 产品 UI
- 云端协作、多用户
- a11y 树、HAR 与步骤自动关联（深度 P3）

## 验证

```bash
pnpm smoke:full
```

macOS 包体还需执行：

```bash
codesign --verify --deep --strict "apps/studio/release/mac-arm64/织流 Studio.app"
hdiutil attach apps/studio/release/FlowWeave-Studio-1.0.0-arm64.dmg -nobrowse -readonly
```
