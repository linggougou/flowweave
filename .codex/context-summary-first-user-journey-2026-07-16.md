- 当前路线：先跑通、再稳定、后智能。
- 生命周期阶段：稳定化收口 / v1 先跑通版维护。
- 当前里程碑：P2 收口；P3 深度智能与 P4 AI 产品化冻结。
- 里程碑真源：`PROJECT_ROUTE_LOCK.md`、`docs/superpowers/plans/2026-05-26-run-first-roadmap.md`。
- 当前阶段出口：新用户可按入口完成扩展录制、同步知识库、Studio 回放与执行诊断查看。
- 本轮最小可验收闭环：按真实入口启动产品，实际检查准备、录制/同步、回放、结果查看各触点，并形成用户旅程与预期符合度判断。

## 审查边界

- 允许修改：本上下文、`.codex/operations-log.md`、`.codex/verification-report.md`。
- 禁止修改：产品代码、测试、配置、路线锁、产品/设计真源与用户数据合同。
- 明确非目标：实现体验优化、解冻 P3/P4、改变页面体系或技术栈、替用户作产品路线决策。
- 变更判断：不涉及新需求实施、阶段切换或高危动作；发现的问题仅作为审查结论，不直接编码。

## 强制检索与证据来源

- 项目规则与路线：`AGENTS.md`、`PROJECT_ROUTE_LOCK.md`。
- 产品与里程碑：产品设计、run-first roadmap、quickstart、manual QA、Web/产物指南。

- 工作区：任务开始时 Git 工作区洁净；保护后续出现的非本轮改动。

## 风险

- 产品跨扩展、桌面端与 Web 三个表面，首次使用成本可能主要发生在安装和跨端切换，而非单个页面内。
- Chrome 扩展加载与 Electron 窗口需要本机 GUI；若自动化表面受限，必须区分“产品缺陷”和“本轮未能验证”。
- 仓库已有演示数据可能让空状态与真正首次使用不同；需要同时核对首次空状态文案和当前实际数据体验。
